# Assignment 4 — Git & GitHub

Repository: https://github.com/krishnaChandak044/tutedude-assignment-4-git

This is a Flask to-do app with `/api` JSON, a form with Item Name/Description/ID/UUID/Hash and POST `/submittodoitem`. The assignment workflow requires SSH setup, feature branches, merge conflict resolution, independent field commits, a soft reset, and rebase. `docs/git-workflow.sh` is an instructional transcript template; this repository's current history contains the pushed baseline. Actual branch history completion still requires running the workflow in a fresh clone. The workstation key authenticated as a different GitHub account than the active `gh` account, so no SSH key was added to the user's GitHub account. The remote currently uses HTTPS.

Run: `pip install -r project/requirements.txt && cd project && python app.py`.
